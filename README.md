# Hopfield Network Memory Attractor Canvas

## 概要
ホップフィールドネットワークに5×5グリッドパターンを記憶させ、ノイズ付きパターンを入力して想起過程をアニメーション表示する教育的ビジュアライゼーション。

## 機能
- 5×5 グリッド（25ニューロン）のバイナリ状態（+1/-1）
- 学習フェーズ:
  - グリッドをクリックして最大4パターンを描画・保存
  - プリセットパターン: X, +, Z, 枠, 対角線
  - Hebb則による重み行列計算 W = (1/N) Σ ξ_μ ξ_μᵀ
- 想起フェーズ:
  - ノイズスライダー（0〜50%）でビット反転
  - 同期/非同期更新モード
  - アニメーション速度調整
- エネルギー関数 E = −½ sᵀWs の収束プロット（Canvasリアルタイム描画）
- パターン比較パネル: 元パターン / ノイズ入力 / 想起結果の並列表示
- 重み行列のカラーヒートマップ（25×25）
- ページロード時にX・+パターンをデモ用に自動保存

## 使い方
1. フェーズ1でパターンを描画して "Store Pattern"（プリセットも利用可）
2. フェーズ2でノイズ量を設定して "Add Noise"
3. "▶ Run" で想起プロセスを開始・エネルギー収束を観察
4. パターン比較パネルで想起精度を確認
